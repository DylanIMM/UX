Las imágenes de escenarios y tarjetas son decorativas; no representan plantas registradas, huertos reales ni publicaciones de usuarios. Para ver la composición de pantallas y sus estados, consulta `../pantallas de aplicación/`.

Los íconos y el logotipo no son archivos de imagen independientes: se dibujan como SVG en los componentes de la aplicación. Usa las capturas como referencia para conservarlos y evitar sustituirlos por íconos inventados.
